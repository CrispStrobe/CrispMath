CrispMath v1.2.0 — connected notepad and graph workspace

v1.2.0 is about working on one calculation instead of retyping it: the
notepad and the graph workspace share a document, so an expression you
type once can be plotted, traced and exported without copying it across
screens. Most of the work is responsiveness — expression caching,
persistent workers and lazy tabs stop repeated evaluation from blocking
the UI — and the release also restores the German, French and Spanish
localizations.

────────────────────────────────────────────────────────────────────

## Calculation and graphs

Compiled expressions are cached per document, so editing one row no
longer recomputes the whole sheet. Worker isolates persist across
calculations and tabs load lazily; large documents open without a
noticeable stall, and document-level storage keeps one save per
workspace instead of per widget.

Graph work gains the features that make a plot usable rather than
merely visible:

- Trace a curve with touch or keyboard and export the sampled values as
  a table.
- Fit finite samples and edit axis bounds directly on the plot.
- Undo graph changes, including function edits from the context menu.
- Edit or remove a plotted function from the graph itself.

## Notepad ↔ graph

Expressions link to graphs through their document variables, so
changing `a` in the notepad updates every dependent curve. The same
document backs both surfaces: switching tabs preserves state, and a
worksheet export captures the linked result rather than a screenshot.

## Finding things

A searchable palette exposes every command and module, which matters
now that the tool set spans algebra, calculus, statistics, matrices,
units and the puzzle labs. Chrome was compacted to roughly one row per
screen: worksheet actions are app-bar glyphs plus menu entries, and the
per-result accuracy and digit-count lines moved into the context menu.

## Optional AI translation

Expression translation by an AI provider is off unless configured.
When enabled, every translated expression is shown for review before it
is calculated — the app never silently evaluates model output.
Requests support cancellation, timeout and retry, and failures fall back
to the original expression.

## Desktop packaging and OCR

Desktop artifacts now bundle the OCR runtime and its CPU dependencies,
and installed-library resolution is verified on Linux, Windows and
macOS, so handwriting import does not depend on a system install. Saved
documents are recovered when their index is damaged, and legacy storage
migrates without overwriting newer records.

Artifacts published with the `v1.2.0` tag, all built from
`de3959dc42439695a52c763e77df49f5815d824f`:

**macOS** (`crisp_math-v1.2.0-macos.zip`, 42 MB) — build requires macOS

**iOS** (`crisp_math-v1.2.0-ios-unsigned.zip`, 15 MB) — inspection

**Linux** (`crisp_math-v1.2.0-linux-x64.tar.gz`, 40 MB) — unpack and run
`bundle/crisp_math`.

**Windows** (`crisp_math-v1.2.0-windows-x64.zip`, 27 MB) — unpack and
run `crisp_math.exe`; the bundle carries the Flutter runtime, the
embedding DLLs and `libsymbolic_math_bridge.dll`.

**Android** (`crisp_math-v1.2.0-android.apk`, 111 MB) — unsigned;
install with `adb install crisp_math-v1.2.0-android.apk`.

**Web** (`crisp_math-v1.2.0-web.zip`, 22 MB) — the same bundle served
at both web hosts.
